# java-calculator-precourse
----

## 기능 리스트
### 1. 입력 처리 기능
- 콘솔을 통해 문자열 입력 받기
  - 예: "덧셈할 문자열을 입력해 주세요."
- 입력값이 null 또는 빈 문자열일 경우 0 반환
  - 예: "" => 0


### 2. 기본 구분자 처리 기능
- 문자열에 포함된 숫자를 쉼표 또는 콜론 기준으로 분리
- 분리된 문자열을 정수로 변환 후 합계 반환
  - 예: "1,2,3" => 6
  - 예: "1,2:3" => 6

### 3. 커스텀 구분자 처리 기능
- 문자열이 "//"로 시작하는 경우 커스텀 구분자가 존재함을 인식
- "//"와 "\n" 사이의 문자를 구분자로 추출
- 분리된 각 문자열을 int로 변환 후 합계를 계산하여 반환
  - 예: "//;\n1;2;3" => 6

### 4. 예외 처리 기능
- 분리된 문자열을 변환할 때 음수인 경우 예외 발생
  - IllegalArgumentException("음수는 입력할 수 없습니다: " + number)
- 잘못된 입력 형식(// 뒤에 구분자가 없거나 \n이 누락된 경우 등)
  - IllegalArgumentException("잘못된 구분자 형식입니다.")
- 숫자가 아닌 값 포함 시
  - IllegalArgumentException("숫자가 아닌 값이 포함되어 있습니다.")
- 예외 발생시 에러 메시지를 출력하고 프로그램 종료

### 5. 출력 기능
- 결과값을 명시된 출력 형식에 따라 콘솔에 출력
  - 예: 결과 : 6
- 예외 발생 시 에러 메시지 출력
  - 예: "음수는 입력할 수 없습니다: -1"
